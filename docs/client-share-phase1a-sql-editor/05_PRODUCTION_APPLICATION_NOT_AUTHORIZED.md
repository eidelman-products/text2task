# Production Application Is NOT Authorized By This Package

Read this even if every test in this package passed.

## What passing these tests proves

That the Client Share Link Phase 1A database design — the tables,
constraints, RLS policies, grants, and cross-table integrity triggers in
`202608030003_client_share_owner_foundation.sql`,
`202608030004_client_share_session_foundation.sql`, and
`202608030005_client_share_integrity_and_security.sql` — behaves as
intended when applied to an isolated, empty, temporary Supabase project
with a minimal fixture standing in for the real Text2Task base schema.

## What passing these tests does NOT prove or authorize

- It does not prove the fixture in `01_CREATE_TEMP_TEST_FIXTURE.sql`
  matches the real, current Text2Task production schema in every detail.
  It is a deliberately minimal stand-in covering only the columns the
  Client Share migrations reference by foreign key.
- It does not authorize applying
  `202608030003_client_share_owner_foundation.sql`,
  `202608030004_client_share_session_foundation.sql`, or
  `202608030005_client_share_integrity_and_security.sql` to the real
  Text2Task production database.
- It does not replace a review of the actual production schema (the "D1"
  pre-Phase-1B decision in
  `docs/TEXT2TASK_CLIENT_SHARE_LINK_PHASE_0_MAPPING_2026-08-03.md` and
  `docs/TEXT2TASK_CLIENT_SHARE_LINK_PHASE_1A_DATABASE_FOUNDATION_REPORT.md`
  still stands regardless of this package's results).

## Hard rules

- The production Text2Task Supabase project must **never** receive
  `01_CREATE_TEMP_TEST_FIXTURE.sql`. That file's own safety check refuses
  to run if it detects a non-empty project, but it should never be
  attempted there in the first place.
- The production Text2Task Supabase project must **never** receive
  `03_RUN_PHASE1A_RUNTIME_TESTS.sql`. Even though that file wraps
  everything in `BEGIN; ... ROLLBACK;`, it is not a script written or
  reviewed for production execution, and it depends on the file 01
  fixture existing.
- Only the three original, already-committed migration files —
  `202608030003_client_share_owner_foundation.sql`,
  `202608030004_client_share_session_foundation.sql`, and
  `202608030005_client_share_integrity_and_security.sql` — are ever
  candidates for eventual production application, and only exactly as
  written, never as edited copies.
- Production application requires a **separate, explicit, later decision**
  by the project owner, made after reviewing this package's results
  together with the Phase 1A report's "Conflicts requiring human
  decision" section and the Phase 0 mapping's pre-Phase-1B blocking
  decisions (D1-D6). It is not a foregone conclusion just because a
  temporary-project test run passed.
- No production bundle, and no production-application script, was
  generated by this task. This package produces only test-project
  artifacts.
