### Why row 8 has no embedded hash

`MANIFEST.md`'s own SHA-256 depends on its own complete byte content,
including whatever line states that hash -- embedding it would require the
file to contain the hash of itself-plus-that-hash, which has no fixed point
in general and is not attempted here. Instead, the generator computes
`MANIFEST.md`'s SHA-256 immediately after writing it and prints that value to
the console (see this script's own `MANIFEST_SHA256=` output line) rather
than fake or hand-paste a self-referential value into this file.
